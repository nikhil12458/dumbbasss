## Purpose

An accordion-style FAQ section addressing common client questions like pricing and timelines.

## Features
- Uses HTML `<details>` and `<summary>` elements for native, accessible accordion behavior without extra JavaScript state.
- Plus icon rotates into an "X" when the detail is open using standard CSS `group-open:rotate-45`.
- Contains realistic boilerplate questions to help the owner structure their consultation flow and pricing signal.
