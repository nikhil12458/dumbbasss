## Key Design Decisions

1. **Static Generation (SSG)** — All project and service detail pages use `generateStaticParams` for build-time rendering.
2. **No CMS** — Content lives in typed data files (`projects.ts`, `services.ts`) for simplicity and type safety.
3. **Design tokens in CSS variables** — The original `shared.css` palette was preserved as CSS custom properties rather than Tailwind theme extensions, keeping the migration faithful.
4. **Physics engine as a utility** — The kinetic typography canvas was ported as a standalone TypeScript module (`kinetic-type.ts`) and wrapped in a React component, keeping concerns separated.
5. **SEO First** — Dynamic meta tag generation per project and globally defined OpenGraph / Twitter metadata.
6. **Optimized Load (Lazy loading)** — The heavy Canvas rendering component is lazily loaded via `next/dynamic` to ensure rapid First Contentful Paint.
