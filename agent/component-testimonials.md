## Purpose

A hanging "kakemono-card" layout for client testimonials that sways gently, matching the site's kinetic/physics aesthetic.

## Features
- Displays a grid of testimonial cards.
- Each card has a `kakemono-sway` animation (defined in `globals.css`) with staggered animation delays so they don't sway in perfect unison.
- Uses placeholder text to emphasize that fake testimonials shouldn't be used.
- Contains a subtle wave texture SVG background for atmosphere.
